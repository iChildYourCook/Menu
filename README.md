# Все свои — конструктор меню

Редактор листа A3. Разделы, название и линейку можно перетаскивать и менять в размере. Шрифт, кегль и межстрочный интервал задаются для всего меню или для одного блока. Блюда перетаскиваются между разделами. Граммовка и цена стоят на одной линии у знака `/`.

Нужен [Node.js 20 или новее](https://nodejs.org). При первом запуске компьютер должен быть в интернете: скачаются библиотеки и шрифты.

## Windows

Распакуйте архив и дважды щёлкните `start.bat`.

Откроется http://localhost:4317

## macOS и Linux

В папке проекта:

```bash
chmod +x start.sh
./start.sh
```

Либо вручную:

```bash
npm install
npm run dev
```

Затем откройте http://localhost:4317

Раскладка сохраняется в этом браузере. Кнопки «Скачать PNG» и «Скачать PDF» собирают лист A3. «Исходное меню» возвращает стартовый вид.
